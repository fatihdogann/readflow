Local-first · personal project

Keep what you read, don’t just save it.

Readflow turns links, text and PDFs into a clean reading view, keeps your highlights, and writes summaries with the coding-agent CLI on your own computer. No API keys, no accounts.

Problem and solution

Reading lists fill up, but little of what gets read is remembered. AI summary tools want your text and an API key in their cloud, and your archive stays tied to that service.

Readflow keeps the archive in a single SQLite file. Summaries and rewrites are handed to the claude, codex or jcode CLI you already use. Highlights and notes build up as you read and gather on one page.

Features

Where a reader meets an archive. Not a chatbot.

Content from anywhere

URLs, plain text, PDF, Word, Markdown, and a bookmarklet for bot-protected pages.

Clean reading

Sanitized text with ads and navigation stripped by Readability.

Highlights and notes

Three colors, notes, every highlight on one page, copy as Markdown.

AI via your local agent

Short, normal or detailed summaries and readability rewrites, with an immutable history for every output.

Four separate versions

The original never changes; your edit, the AI rewrite and the summary are stored separately.

Export

Markdown, TXT, DOCX, PDF; optional Notion and Telegram.

Architecture

The web UI never runs AI work itself: it writes a pending job to SQLite. A local worker leases the job, runs the CLI and writes the result back.

Data is stored locally. Which model does the AI work depends on your CLI: if it talks to a remote model, the processed text goes to that provider.

Security decisions

  • The app listens only on 127.0.0.1; remote access goes through Tailscale Serve.
  • Single-user login, signed HttpOnly session cookie, origin checks.
  • In production the app refuses to start without credentials.
  • SSRF protection with a DNS lookup before every fetch.
  • Agent commands run without a shell; CLI flags are verified against --help output.
  • Data directory is 0700, database 0600; user data never enters Git.

Setup preview

The source code isn’t public yet. Once it is, setup will look like this:

# Requires Node 22+ and pnpm
git clone <repo> readflow && cd readflow
pnpm install
pnpm build
# Sign in to your claude / codex / jcode CLI first
pnpm app:start      # http://127.0.0.1:3000
